1. O que é Flexbox?

Flexbox é um modelo de layout do CSS utilizado para organizar elementos em uma dimensão: linha ou coluna. Ele facilita o alinhamento, a distribuição de espaço e a adaptação dos elementos a diferentes tamanhos de tela.

É muito utilizado em menus, barras de navegação, botões, cartões e componentes de páginas web.

2. Como funciona?

Para utilizar o Flexbox, aplicamos display: flex; ao elemento pai. Esse elemento passa a ser o contêiner flexível, e seus filhos diretos são chamados de itens flexíveis. 

.container {
    display: flex;
}

3. Principais propriedades

  • flex-direction: define a direção dos itens, como row ou column.
  • justify-content: distribui os itens no eixo principal.
  • align-items: alinha os itens no eixo transversal.
  • flex-wrap: permite que os itens passem para outra linha.
  • gap: define o espaço entre os itens.
  • flex-grow: determina como um item pode crescer para ocupar espaço disponível.
  • align-self: permite ajustar individualmente o alinhamento de um item.

5. Exemplo de código

.container {
    display: flex;
    flex-direction: row;
    justify-content: center;
    align-items: center;
    flex-wrap: wrap;
    gap: 16px;
}

.item {
    flex: 1 1 150px;
}

Nesse exemplo, os itens ficam organizados em linha, centralizados e com espaçamento. Se faltar espaço, eles podem passar para outra linha. A propriedade flex permite ajustar seu crescimento e tamanho inicial.

6. Vantagens e aplicações

  • Facilita o alinhamento horizontal e vertical.
  • Ajuda a criar interfaces responsivas.
  • Distribui o espaço disponível entre os elementos.
  • É indicado para menus, barras e componentes em uma dimensão.

Conclusão

O Flexbox simplifica a organização dos elementos em linhas ou colunas. Quando combinado com outras propriedades CSS, permite criar interfaces organizadas e adaptáveis.

CSS Flexbox

Aprende a organizar, alinhar e distribuir elementos de forma flexível nas páginas web.

O que é Flexbox?

Flexbox significa Flexible Box Layout. É um modelo de layout CSS que permite organizar elementos ao longo de um eixo principal, numa linha ou numa coluna. É muito utilizado em menus, botões, cabeçalhos e cartões. 

.container {
    display: flex;
    gap: 16px;
}

1. Os dois eixos

Eixo principal

É a direção em que os elementos são organizados. A propriedade flex-direction define essa direção.

Eixo transversal

É perpendicular ao eixo principal. A propriedade align-items controla o alinhamento neste eixo.

2. Propriedades básicas

PropriedadeFunção
display: flexAtiva o Flexbox.
flex-directionDefine linha ou coluna.
justify-contentDistribui os itens no eixo principal.
align-itemsAlinha os itens no eixo transversal.
gapDefine o espaço entre os elementos.
flex-wrapPermite passar os itens para outra linha.

4. Conceitos intermédios

flex-grow

Controla a forma como os itens crescem para ocupar espaço disponível.

flex-shrink

Controla a forma como os itens encolhem quando falta espaço.

flex-wrap

Permite que os elementos passem para outra linha.

align-self

Permite alterar o alinhamento de um item individual.

Quando utilizar Flexbox?

O Flexbox é ideal para menus de navegação, botões, barras de ferramentas, cabeçalhos e grupos de elementos organizados numa direção principal.

CSS Flexbox

Aprende a organizar, alinhar e distribuir elementos de forma flexível nas páginas web.

O que é Flexbox?

Flexbox significa Flexible Box Layout. É um modelo de layout CSS que permite organizar elementos ao longo de um eixo principal, numa linha ou numa coluna. É muito utilizado em menus, botões, cabeçalhos e cartões. 

.container {
    display: flex;
    gap: 16px;
}

1. Os dois eixos

Eixo principal

É a direção em que os elementos são organizados. A propriedade flex-direction define essa direção.

Eixo transversal

É perpendicular ao eixo principal. A propriedade align-items controla o alinhamento neste eixo.

2. Propriedades básicas

PropriedadeFunção
display: flexAtiva o Flexbox.
flex-directionDefine linha ou coluna.
justify-contentDistribui os itens no eixo principal.
align-itemsAlinha os itens no eixo transversal.
gapDefine o espaço entre os elementos.
flex-wrapPermite passar os itens para outra linha.

4. Conceitos intermédios

flex-grow

Controla a forma como os itens crescem para ocupar espaço disponível.

flex-shrink

Controla a forma como os itens encolhem quando falta espaço.

flex-wrap

Permite que os elementos passem para outra linha.

align-self

Permite alterar o alinhamento de um item individual.

Quando utilizar Flexbox?

O Flexbox é ideal para menus de navegação, botões, barras de ferramentas, cabeçalhos e grupos de elementos organizados numa direção principal.

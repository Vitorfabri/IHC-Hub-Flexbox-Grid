Aprendendo CSS Grid

Organizando elementos em linhas e colunas

Início Flexbox Grid

1. O que é CSS Grid?

CSS Grid é um sistema de layout que permite organizar elementos em duas dimensões: linhas e colunas. Ele facilita a criação de estruturas de páginas com áreas bem definidas e distribuição controlada do espaço.

É muito utilizado para organizar galerias de imagens, cartões, painéis, páginas de notícias e estruturas completas de sites.

2. Como funciona?

Para ativar o Grid, utilizamos display: grid; no elemento pai. Em seguida, definimos a quantidade e o tamanho das colunas e, quando necessário, das linhas. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 12px;
}

A unidade fr representa uma fração do espaço disponível. Nesse exemplo, são criadas três colunas com proporções iguais.

3. Principais propriedades

  • grid-template-columns: define as colunas do layout.
  • grid-template-rows: define as linhas.
  • gap: determina o espaço entre linhas e colunas.
  • grid-column: controla em quais colunas um item aparece ou quantas ocupa.
  • grid-row: controla em quais linhas um item aparece ou quantas ocupa.
  • justify-items: alinha os itens horizontalmente dentro de suas áreas.
  • align-items: alinha os itens verticalmente dentro de suas áreas.

5. Exemplo de código

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

.destaque {
    grid-column: span 2;
}

A função repeat evita repetir a definição de cada coluna. Já grid-column: span 2 faz o item ocupar duas colunas. O espaçamento entre os elementos é definido por gap.

6. Responsividade

Com media queries, podemos alterar o layout conforme a largura da tela. Neste exemplo, em telas de até 600 pixels, o Grid passa a ter duas colunas. 

@media (max-width: 600px) {
    .container {
        grid-template-columns: repeat(2, 1fr);
    }
}

7. Vantagens e aplicações

  • Permite controlar linhas e colunas simultaneamente.
  • Facilita a criação de layouts complexos.
  • Permite que elementos ocupem várias linhas ou colunas.
  • Ajuda a criar páginas responsivas e organizadas.

Conclusão

O CSS Grid é uma ferramenta importante para construir layouts em duas dimensões. Com linhas, colunas, espaçamentos e áreas, conseguimos organizar o conteúdo de maneira clara e flexível.
